# agenticcarekit

> agenticcarekit — the open-model stack for health AI. Runs on your laptop. Ships with the privacy boundary built in.

**Status: Phase 0 (contracts frozen). Full toolkit landing in staged commits — see `docs/brief.md` for the design.**

`ack init` interrogates your machine, recommends an open-weight model, and
generates a production-shaped healthcare AI project you fully own. A
scaffolder, a thin runtime, and a local sidecar — not a framework: nothing
inverts control, nothing hides the provider, every abstraction is ejectable.

- **No telemetry, ever.**
- Decision-support scope only: documentation, navigation, accessibility,
  triage routing, education. Not diagnosis, not treatment. Synthetic or
  public data only.
- `ack` is the command; `agenticcarekit` is the package. Not affiliated
  with, endorsed by, or derived from Apple Inc.
